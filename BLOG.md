# Automate the TON Blockchain with Our New n8n Community Node

We're excited to announce the release of n8n-nodes-ton, a powerful new community node that brings TON blockchain automation to n8n! Developed by Velocity BPA, this node enables seamless integration with The Open Network (TON) blockchain directly within your n8n workflows.

## Why We Built This

As blockchain technology continues to evolve, TON has emerged as a fast, scalable platform powering everything from cryptocurrency transactions to decentralized applications. However, interacting with TON programmatically has traditionally required significant technical expertise and custom code development.

Businesses and developers need a way to automate blockchain operations without writing complex scripts for every task. Whether you're monitoring wallet balances, managing NFT collections, interacting with smart contracts, or handling Jetton tokens, these operations should be as simple as connecting nodes in a visual workflow.

## Key Features

Our n8n-nodes-ton brings comprehensive TON blockchain functionality to your fingertips:

- **Wallet Operations**: Monitor balances, send transactions, and manage multiple wallets effortlessly
- **Jetton Token Support**: Handle fungible tokens on the TON network with ease
- **NFT Management**: Create, transfer, and track NFT collections and items
- **Smart Contract Interactions**: Call contract methods and deploy new contracts directly from your workflows
- **DNS Operations**: Resolve and manage TON DNS domains
- **Staking Capabilities**: Automate staking operations and monitor rewards

All of these features are accessible through n8n's intuitive visual interface, meaning you can build sophisticated blockchain automation without writing a single line of code.

## Getting Started

Installing the node is straightforward. Simply run the following command in your n8n installation directory:


npm install n8n-nodes-ton


After installation, restart your n8n instance, and you'll find the TON node available in your node palette.
